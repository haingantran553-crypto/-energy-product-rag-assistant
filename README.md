# 新能源产品资料问答助手

面向便携式储能电源售前资料核查的单用户网页原型。上传产品说明书后，查询参数、比较型号、检查使用条件，查看答案对应的原文与PDF页序；资料不足时提示无法确认。

参考[langchain-ai/rag-from-scratch](https://github.com/langchain-ai/rag-from-scratch)基础索引、检索与生成教学流程，完成业务适配和功能改造，并非完整复现全部仓库或从零发明RAG算法。代码由ChatGPT辅助实现，个人工作包括场景与边界定义、功能取舍、Windows集成、原文核验、失败分析和真实复测。来源与许可边界见[来源说明](docs/SOURCES_AND_LICENSE.md)。

当前为`6.6.1-correction-selection`发布候选，尚未上传GitHub或投入生产。主提示词6、检索v6.6-unit-field-hybrid-neighbors；来源复用范围和代码许可证仍有待确认项。

## 功能与边界

| 需求 | 当前功能 | 边界 |
| --- | --- | --- |
| 参数分散、相近型号易混用 | 全局向量候选＋每文件BM25、有限字段/接口/方向规则、同页邻块补充 | 不是通用语义校验，规则有限 |
| 出处难核查 | 保留编号，分别展示实际引用和未引用候选 | 编号存在不代表引用支持结论 |
| 重启不想重复嵌入资料 | 命名知识库，保存资料/块/向量/版本，重开复用向量 | 查询仍调用嵌入和聊天接口，配置不兼容时拦截 |
| 历史记录容易丢失 | 本地SQLite保存问答、原文、评分、备注及校正轨迹，按库/资料版本恢复 | 单用户本地原型，没有多用户权限 |
| “那Max呢”等省略追问 | 根据当前对话上一问题有限补全，并保存原问题与检索问题 | 不把旧答案当参数证据，歧义时规则澄清，不支持任意长对话推理 |
| 正确数值引用错误片段 | 部分数值/范围/限定词疑点检查，最多一次校正，校正不改善时保留首次答案和警告 | 检查不能证明全部语义，可能误报/漏报，仍需人工核验 |

无OCR；PDF表格文字可能混排。本项目不查询实时售价/库存，不提供生产客服承诺，没有真实业务用户量或业务效率提升数据。

## 快速启动

验证平台：Windows、用户提供的Python3.12.7。2026-11-06用户确认在同一台Windows的新独立虚拟环境安装原始124项固定依赖后，pip check、12项无API自检、网页启动、打开原知识库及历史恢复通过。这不是新电脑、Linux或生产部署验收。

在含app.py的目录使用PowerShell（已配置Python3.12的py启动器）：

```powershell
py -3.12 -m venv .venv
& ".\.venv\Scripts\python.exe" -m pip install -r .\requirements.txt
& ".\.venv\Scripts\python.exe" -m pip check
& ".\.venv\Scripts\python.exe" .\verify_v661.py
Copy-Item .env.example .env
```

若没有py启动器，使用已安装的Python3.12解释器绝对路径执行`-m venv .venv`。在VS Code编辑本地.env，填写自己的密钥和兼容接口地址。已验证模型为`XingChenAGI/Xing4.0-29B`和`BAAI/bge-m3`；示例地址是占位符，不是可直接使用的服务配置。

```powershell
& ".\.venv\Scripts\python.exe" -m streamlit run app.py --server.port 8504
```

打开[http://localhost:8504](http://localhost:8504)，保持终端运行；Ctrl+C停止。

首次使用：按[资料来源](docs/SOURCES_AND_LICENSE.md)下载说明书，左侧“上传并建立”→“创建新知识库”→上传该版本全部PDF/TXT→“建立并保存新版本”。已有库选择“已保存知识库”→库和资料版本→“打开所选版本”。更新选择“为已有知识库建立新版本”，旧版保留，成功后切换。

本包不包含本地.env、_local_kb和历史，新使用者应自行配置并建库。不要将个人知识库或完整原文评测误提交到Git。

## 真实评测证据

固定开发题集20题：17题有参数事实，3题资料不足；两款真实产品为EcoFlow RIVER 2与RIVER 2 Max，固定中文V1.0手册各15页，总30页/45块，切块350字符、重叠60。TEST-A为虚构软件测试资料。

| 版本与口径 | 实际记录 | 能说明什么 |
| --- | --- | --- |
| v6.3检索对照，严格候选文字证据覆盖 | 纯向量2/17，混合流程16/17 | 向量最多6段，混合6–10段；整体流程对照，不是单独BM25贡献、经典Recall@k或问答准确率 |
| v6.5.1完整20题严格总体 | 每题首次15/20；纳入实际手动重问后17/20 | 3次首次超时保留；08/16/17仍有引用或限定词失败 |
| v6.6三题专项 | 最终3/3，08含一次自动校正 | 首次模型生成2/3，不能当全部首答正确 |
| v6.6四题回归 | 纳入C03实际手动重问后3/4 | C02校正反而删除正确引用，首次连接失败保留 |
| v6.6.1 C02真实专项 | 最终通过，2次模型生成、1次自动校正 | 校正将126W引用改到实际支持片段；单次总用时124.8056秒，不是提速证据 |
| v6.6.1开发离线检查 | 197项通过 | 模拟API配真实本地组件，不等于197道真实API问答 |

同题集已用于开发，非独立盲测；版本与首次/重问/自动校正结果分开留证。当前v6.6.1没有完整20题问答成绩，不跨版本拼20/20，不宣传引用准确率100%。[完整评测边界](docs/EVALUATION.md)。

## 模块与使用说明

| 文件 | 职责 |

| app.py | 网页、解析、切块、检索、生成、引用及交互 |

| verify_v661.py | 12组无API自检，使用临时数据库 |
